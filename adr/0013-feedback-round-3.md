# ADR 0013 — Product Owner Feedback, Round 3

Decisions made directly by the product owner (or required to implement their
requests). They supersede conflicting statements in earlier docs.

## Agents never silently die
A terminal agent whose process exits with an error after running for at least
10 seconds is restarted automatically (resuming its conversation where the CLI
supports it). At most 3 recoveries per agent in 5 minutes; after that it stays
stopped and shows the error. Clean exits and start-up failures are left alone.
The renderer also never sends a terminal size below 12×4 (hidden, collapsing or
minimized hosts).

## Main workspace can be removed
Main is never deleted from disk, but it can be *removed* from Hiveory: its agents
stop and close and the record is forgotten; the project folder is untouched and
Main can be created again. AGENTS.md rule 12 was updated accordingly.

## Right-click menus
Sidebar project and workspace rows open their actions on right-click (or the
keyboard context-menu key); the ⋯ buttons are gone from the sidebar. Workspace
actions are one shared list (`workspace-menu.tsx`) used by the sidebar and the
workspace cards.

## Shell layout
- Both sidebars are resizable by dragging their edge (arrow keys too; double-click
  resets). Widths are a per-viewer convenience kept in localStorage.
- The left-sidebar toggle is highlighted while the sidebar is shown.
- ~~"New workspace" lives at the right end of the title bar~~ — superseded by
  ADR 0014: it sits at the right end of the project page's tab bar.

## Side panel
Starts empty with a "+" menu (Terminal, Browser). Any number of tabs per folder;
each terminal tab is its own shell (`shell.open` with a `tab` id). Browser tabs
are placeholders until the browser ships. The panel can be maximized: it then
overlays the main area up to the left sidebar, while the main area keeps its size
(agent terminals never reflow). Side-panel PowerShell uses a compact prompt
showing only the folder name.

## Path display
`PathTrail` is one control: a root chip (home, drive, or a Hiveory-managed
workspace folder shown as project › workspace without the id suffix), the
meaningful folders, then copy and open. It measures its own width and collapses
to "… › last folder" when narrow.

## Chat view in Work
Workspaces and presets gain **Use chat UI** next to auto-approve. When on,
agents whose CLI has a headless mode render the same conversation and composer as
Chat mode, backed by a chat with the agent's id (`ChatSession.agentId`); those
chats never appear in the Chat list. CLIs without a chat mode — Antigravity
deliberately — keep their terminal. A chat-view agent is always ready (running)
and is "working" while a reply streams, so the Kanban and agent tools treat it
like any agent (`read_agent` returns its transcript, `send_message` sends a turn).
Its CLI and folder are fixed. AGENTS.md rule 14 now lists the chat UI setting.

Settings → Agents adds defaults for **Auto-approve permissions** and **Use chat
UI**; they pre-fill the create-workspace and preset dialogs.

## Themes
A third theme, **Dark** (now the default): pure black and neutral grey with no
hue, gradients or sheen. Component fills are tokens (`--fill-*`) that Bronze and
Silver render as gradients and Dark flattens to single colors.

## Details
- Composer pickers are one connected toolbar (CLI · model · effort · folder).
- The project sort icon is "list filter".
- Development builds use `resources/icon-dev.png` (the logo with a white DEV
  mark, generated by `scripts/generate-dev-icon.py`) as the taskbar icon.
- The segmented mode switch has equal insets on all sides.
