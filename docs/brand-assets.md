# Integration brand assets

`src/apps/renderer/src/shared/ui/HiveoryBrandIcon.tsx` is the sole renderer registry for official integration marks. It bundles unmodified geometry from `simple-icons` (CC0-1.0) for Cloudflare, GitHub, Gmail, Jira, Linear, Notion, Shopify, Stripe, Supabase, and Vercel, and from `@fortawesome/free-brands-svg-icons` (CC-BY-4.0) for Slack. The marks are used only to identify the matching integrations; each provider retains its trademark rights.

The registry follows the corresponding vendor resources: Cloudflare press kit, GitHub brand toolkit, Google brand guidance, Linear brand resources, Notion brand guidelines, Shopify brand assets, Slack media kit, Stripe media assets, Supabase's official repository asset, Vercel brand guide, and Atlassian logo guidance. Official colors remain inside the allowlisted registry; Hiveory interface chrome must continue to use the design-system tokens.
