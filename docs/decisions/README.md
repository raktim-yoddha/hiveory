# Architecture Decision Records

ADRs are historical, append-only records of decisions and their original context. Status is accepted unless the document says otherwise or a later ADR supersedes it. An older ADR can describe a phase limitation that the current product has since removed; use the [current architecture documentation](../architecture/README.md) for implemented behavior.

Do not rewrite an accepted ADR to match later code. Add a new ADR that supersedes it and link both records.
