# Dated design specifications

These specifications are historical design inputs. They record intended behavior before or during implementation and may contain superseded terminology, paths, assumptions, or non-goals. They are not proof that a feature shipped.

Use the root [README](../../../README.md) for current user-facing behavior and the [architecture index](../../architecture/README.md) for implemented boundaries. When a specification and current code differ, update the maintained architecture document and preserve the dated specification as provenance.
