# Planned / proposed features

**Status:** No active product roadmap is asserted by this index. Ideas, dated specs, phase records, or identified engineering risks are not commitments.

Add proposals here only when an owner deliberately maintains them as uncommitted ideas. Each proposal must name the current source gap, rationale, and testable acceptance criteria. Keep proposals prioritized and clearly label them as uncommitted. When shipped, move verified behavior to `implemented/` and remove the proposal in the same change. Rejected or superseded durable policy belongs in an ADR when appropriate.

For historical design material, use [specifications](../../superpowers/specs/README.md), [phase records](../../phases/README.md), and [ADRs](../../decisions/README.md). These records do not create a current roadmap.
