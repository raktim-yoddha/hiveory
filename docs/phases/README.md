# Phase records

The files in this directory are historical implementation plans. They preserve scope, sequencing, acceptance criteria, and repository structure at the time each phase was executed. They are useful for provenance and regression context but do not define the current feature set.

Use the root [README](../../README.md) for current features and the [architecture index](../architecture/README.md) for current boundaries. Old paths and commands in phase records are evidence of the repository shape at that time.
